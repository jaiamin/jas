# ASS workspace

Mode: Operate. Audience: researchers, developers and enthusiasts experimenting locally.
The user delegated design decisions, requested a full fresh start, minimalist modern SaaS
quality, light/dark themes and no clarification round.

## Direction contract

THESIS: A useful experiment workspace where every conclusion can be followed to its recorded
turn. Familiar tables and navigation, with the experiment question as the point of entry.
OWN-WORLD: Neutral white/black shadcn work surfaces,
monochrome actions, restrained orange selection, Geist, sharp 2–4px radii, compact tables and spacing-led hierarchy.
Dark mode uses black/charcoal surfaces and softer orange selection. No green brand,
status or data colors. The user authorized a full layout redesign using standard shadcn components.
STORY: Ask a question or configure a study; inspect its treatments before spending; monitor
runs; compare evidence; tune into a preserved new revision.
FIRST VIEWPORT: 200px collapsible navigation, 48px breadcrumb bar, a centered 800px question
composer and compact starter buttons, followed by a recent-experiments table. The primary action
sits at the composer's lower right. A live run uses a shared toolbar over its environment view
and recorded evidence; the signature move is a continuous turn rail linking events and inputs.
FORM: Grounded candidates: research repository, documentation index, museum collection,
conference proceedings, field-study notebook, university service identity, clinical registry.
