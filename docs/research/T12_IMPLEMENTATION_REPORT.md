workflow. Exclusive claims and delegation determine who can start work. Starting
validates prerequisite acceptance, artifact/source permissions, exact version,
write allowance and full material cost before mutation. One settlement appends
the version, debits materials and sets a logical due time. Readiness charges
nothing further. Only the selected recipient can accept a completed-version
handoff; that acceptance unlocks dependent work. Handoff read grants and unstarted
delegation change later affordances. Procedure editing and prose execution remain
unsupported.

addressed mail use explicit logical time. Provider latency grants no priority.

distinct terminal facts. Future work/mail can remain pending at the horizon.

platform was installed. Sol remains Researcher/planner; Luna remains the default
model participant. Both existing participant harnesses work through the same
