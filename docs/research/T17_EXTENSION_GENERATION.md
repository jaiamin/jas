## Literal independently specified DEVELOPMENT oracle: refundable permit v1

Frozen before any candidate output. This is DEVELOPMENT, not final held-out.
Roles are grantor(slot0) and holder(slot1), in that logical order independent
of role prose, seed or provider completion order. States are idle(0,escrow0),
live(1,escrow1), redeemed(2,escrow0,successful terminal), and
stopped(3,escrow0,unsuccessful terminal). Initial idle/available2; total resource2.
Spent is `2 - available - escrow`. Valid states require available0..2 and
nonnegative spent. No transition may decrease spent or increase available+escrow.
Thus live/available2 is invalid, and repeated issue/revoke cannot mint resources.

Operations, in fixed encoding order:

1. `issue`(0): only grantor, idle, available>=1; moves live, available-1,
   escrow1. It transfers one available unit to escrow without spending it.
2. `redeem`(1): only holder, live, available>=1; moves redeemed, available-1,
   escrow0. Both the held unit and one available unit are spent.
3. `revoke`(2): only grantor, live; returns the held unit to available and moves
   idle. Holder redemption becomes unavailable. Reissue remains possible.
4. `wait`(3): either role, valid nonterminal state with available>0; no state,
   resource or escrow change. It consumes one normal logical actor turn.
5. `stop`(4): either role, valid nonterminal state with available>0; moves stopped
   with the same available stock and retires any held unit as spent.

Terminal states, available0, invalid resource states, an unauthorized actor or
operation deny atomically. Zero available ends unsuccessfully unless redeemed;
the experiment round horizon ends unsuccessfully without inventing a refund or
advancing time. No transition after termination. An accepted action advances one
normal actor position; rejections consume neither turn nor note/history/evidence.

Input is `(((state*3 + available)*2 + slot)*5 + operation)` in0..119.
Output is `next_state*3 + next_available`, or -1. Independent invalid integers
are **-1,120,2147483647,-2147483648**, all requiring -1. Every one of120 inputs
and four invalid integers is checked twice (248 fresh instances).
