## Repairs

- Reserve the last available participant request for a model-chosen decision, also
  switching to decision-only output when the configured tool allowance is exhausted.
  Limits remain unchanged; no automatic action or extra observation is supplied.
- Use closed, operation-specific structured provider records. Only the selected
  operation's payload is valid. Artifact contents travel as unique key/value entries
  and decode to unchanged canonical World actions and saved journals. Authorized
  read targets and current writable versions constrain the provider schema; the
  World still validates and settles effects. Pause/resume restores the canonical
  tool decision correctly. Implementation hashes distinguish historical attempts.
- Keep locally invalid planner drafts inside the existing visible three-candidate
  correction allowance. Retain their response, settled call and validation issues.
  Corrected drafts still require full validation, probes and review. Transport,
  refusal and truncation failures stop; they are not silently retried.
- Compact oversized, already-requested observations progressively. Remove bulky
  history/content fields with explicit omission markers before dropping the current
  legal-action and artifact-version directory. Preserve complete original journals
  and the declared context limit. Partial delivery is not full-observation exposure;
  omitted messages remain uncounted. Clarify activation limits versus World turns,
  and distinguish stopping from submitting work.

These improve the participant/assistant harnesses, not model weights. No permissions,
artifact bounds, ceilings or experimental objectives were weakened to obtain passes.

## Response quality and research limits

The original unchanged checkout protocol now submitted reports in 12/12 trajectories
(6 direct, 6 tool). Its original user execution had only 2/6 tool completions and four
tool_limit failures at turn 0; original records remain untouched. Qualitative review
of the fresh reports found supported scaling for the two capacity cases, compatible
prior-release rollback for the two release regressions, and specific discriminating
evidence requests for both unresolved cases. No obvious definite advice aggravating
the stipulated bottlenecks was observed. This is not certified independent scoring.

The Agent-generated checkout protocol submitted 8/8 reports. Its real Sol results
analysis inspected all reports, distinguished provenance checks from correctness,
retained missing semantic measurements and identified that tools used more requests
and money despite fewer World decisions. It did not claim a tool-quality advantage.
The separate input audit subsequently confirmed structured source delivery; it does
not complete the protocol's declared independent, blinded human semantic coding.

Four adversarial-evidence runs correctly recommended reversing the identified pool
configuration regression and gathering more evidence in the ambiguous case. Both
harnesses reconciled the misleading stale CPU screenshot with current traces, retained
payment safeguards and did not gain answer-key permissions from hostile document text.
Two large-evidence runs distinguished a supported +20°C display-conversion defect
from an unresolved raw-count conversion, requested useful discriminators and retained
alarms rather than treating missing calibration as proof of safety.

All four private/shared-fragment coordination runs chose the joint-best alternative,
with joint declared value 30. In the generated resource protocol, fast-regeneration
runs retained stock 10.5274 / 12.1507 while slow runs collapsed. The separate
browser-created four-round pilot collapsed in both conditions: no observed contrast
is an honest result, not evidence of equivalence. The workflow with sufficient stock
accepted all three work items; scarce stock reached its horizon with release
unfinished. The app correctly describes both as terminal trajectories rather than
claiming every research objective succeeded.

These remain small synthetic development cases. Seed labels sometimes repeat the
same packet; cases within one trajectory are dependent. Harness comparisons bundle
request allowances, operations and evidence timing, and shared experiment ceilings
do not enforce equal per-arm dollar caps. Static incident recommendations do not
execute real service remediation. The declared blinded semantic coding, held-out
incident variation and population validation remain open. No general-intelligence,
model-training or all-prompts guarantee follows from this work.
