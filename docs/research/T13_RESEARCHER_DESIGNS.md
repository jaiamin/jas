## Implemented boundary and decisions

The existing Sol general-answer handoff, planner, bounded validation/revision and
independent critique remain the only design path. No participant engine or planner
was added. The stale brief minimum of two is now one; World/domain constraints
still decide which populations each installed environment can implement. T09 solo
artifact work is supported; artifact timing/coordination and T10 are not advertised.

The planner dispatches and persists real capability discovery even when entered
directly. Each validated proposed condition is inspected on a copied World using
its actual population, first seed, content, ACLs and settings. Optional bounded
explicit action witnesses use the existing ResearchTools dispatcher and World
rejection atomicity. Results retain candidate/design hash, condition, source,
observation, legal schema, consequences and checkpoint hashes. The planner rejects
failed probes before final critique. Identical operations reuse their recorded
result. Empty witnesses are inspection only; they are not successful trajectories.

A full discovered builtin/library source is pinned automatically or selected by the
candidate. A genuine red found that a correct definition hash with an invented
library record ID previously passed. Full provenance must now equal discovery or
an eligible earlier proposal in the same captured chat. Library editing/deletion
cannot change an existing proposal or immutable revision. Concrete study rules,
participant profiles, models, memory, harness limits and inference settings remain
separate from the reusable mechanics example.

Intent is a declared brief artifact. Exploration can retain conflicting evidence,
revision trajectories, failed/unverified work and stopping without a directional
hypothesis or mandatory scalar endpoint. Confirmation requires advance analysis
text and semantic critique; the program does not pretend that nonempty prose proves
analysis quality. Size rationale covers necessary roles/population, actual action
or harness opportunities, early stopping, conditions, seeds/repetitions, inference
unit and evidence capture. More agents/turns are not independent replication.

Material permission/meaning ambiguity returns a clarification without an executable
proposal. Unsupported mechanics retain the original question and clearly narrower
installed alternatives, without substituting or saving one. The existing general
answer remains useful without a proposal. Public activity retains real results,
not private reasoning. Intent/operationalization appear in existing Study scope and
Protocol notes; the optional analysis field explains exploration versus confirmation.
Stock components/tokens and the existing draft/record identity are retained.

No World/checkpoint, export or persistence semantics changed. These are additive
version-1 research artifacts and stricter new-proposal provenance checks, so
DB7/export8/capture1/comparison1/library4/tool2.0/direct1.0 stay current. No migration,
compatibility alias, reset, dependency change, extension generation/admission,
provider fallback or hidden execution was introduced.
