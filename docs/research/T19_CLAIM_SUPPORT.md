## Decisions before implementation

Use the existing bounded Researcher loop, provider ledger and immutable selected
run cutoffs. Two installed read-only lenses (recorded behavior and communication)
are enough for current Worlds. No extension execution, new analysis engine or
natural-language truth oracle. Each exact assertion identifies a supplied
calculation and its scope. The calculation retains inputs, formula, source links,
membership and assumptions. A numerical match checks that structured assertion
only; generated wording always remains unassessed. An annotation is not a World
fact, and declared causal/intent labels remain unsupported by these lenses.

Existing T06 matching/inference/selection/bounds remain authoritative. T07 exact
request receipts and T08 authorized observations remain the exposure sources:
local reads/references after compaction are not delivery. Missing capture is null,
never fabricated zero. Inclusion is not attention or belief. False factual reports,
feasible commitment breaches and intentional deception remain distinct.

Additive analysis JSON gets its own current version; DB6/export7/capture1/
comparison1/libraryv3/harness2.0.0/direct1.0.0 retain their meanings. No migration,
adapter or reset. Historical analyses without this artifact stay unassessed.

## Independently worked DEVELOPMENT expectations (before outputs)

These are hand-specified correctness/assessment cases, not held-out examples or
live semantic reliability. Deterministic provider fixtures return candidate claims;
they do not generate the expected assessments. No protected benchmark changes.

1. **Totals:** commons, two participants, two rounds, endowment 10, multiplier
   1.5, contribution 2 each. Each receives `10-2+1.5*4/2=11` per round,
   balances **22,22**, total **44**, four decisions, contribution sum **8**.
   An inspected citation plus asserted total **440** is contradicted. Total 44
   is checked only as a captured-run calculation; its prose remains unassessed.
2. **Direction/null:** matched commons arms contribute 0 versus 10. Rates 0
   and 1, treatment minus baseline **+1**, reversed assertion **-1** is
   contradicted. Equal arms have exact descriptive contrast **0**; null is useful
   and does not establish equivalence or a population effect.
3. **Missing support:** seeds 7 and 11; A rates (0,1), B (1,failed). One
   observed pair, difference **+1**, planned bounds **[0,0.5]**. All-planned
   scalar assertion is unavailable. Failed/unmatched/unattempted cells stay
   visible; no invented second trial or independent support.
4. **Absent exposure:** no messages/reports/promises. Their event opportunities
   and confirmed event input are **0** with current capture, but there is still
   possible rule/choice input. Claiming one observed message recipient is
   contradicted. No general claim of attention, belief or deception passes.
5. **False report/breach:** a report opposite the actor's sampled signal is a
   false recorded factual report. A feasible promise of 3 followed by 0 is a
   feasible breach. Neither event establishes intentional deception. Semantic
   paraphrases ("misled", "kept them in the dark", "betrayed") and ambiguous
   restraint remain unassessed; causal/intent declarations unsupported.
6. **Accurate/inconclusive:** a concise literal description with citations and
   matching exact assertions is numerically checked, wording unassessed. An
   honest insufficient-evidence answer with no exact assertions is unassessed,
   never failed merely for abstaining. An invented number in free prose without
   a structured assertion also stays unassessed, never a validity pass.
7. **Freeze/read-only/privacy:** accept an analysis while a participant request
   is in flight, then settle/resume/save a revision. Frozen membership, receipt
   status and calculations must remain unchanged; new lens creates a new
   analysis only. Source turns/events/checkpoints/activation journals and
   participant requests/charges match independent before/after snapshots.
   Unselected run/chat sources cannot be requested or cited. Every Researcher
   request has its own reservation/settlement and analysis identity.
