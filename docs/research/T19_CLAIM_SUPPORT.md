Two installed read-only lenses, `behavior` and `communication`, use the existing
bounded Researcher loop, public workflow and provider ledger. There is no second
analysis engine, extension admission or natural-language truth oracle. A calculation
assertion names a supplied calculation, numeric value, scope and optionally observed
pairs. Inputs, formulas, assumptions, membership and source links are retained.
Relative/absolute numeric tolerance is 1e-12. A match checks that structured assertion
only. Generated wording always remains `prose_status: unassessed`; causal/intent
labels are unsupported. General answers, explanation, planning and copied-probe
workflows retain their response shapes and do not require calculation assertions.

Capture retains cutoff state/accounting, settled actions/events, versioned
measurements, planned T06 support, exact T07 activation/operation/request membership,
and recorded observation windows. Artifact Worlds additionally retain contents,
versions, source references, history, writes remaining and terminal outcome. Utility
is null where that World has no balances; artifact success is null before termination.
The model gets at most 96 calculation summaries with an omission count. Full facts
and inputs remain downloadable; full artifact state is omitted from model index
summaries, with authorized bounded tools available for inspection.

Reanalysis requires the same chat and exact study/run scope, reuses the original
frozen inputs/cutoffs and creates an analysis with its own reservations/settlements.
Later same-chat answers beyond an old cutoff are excluded. Source revisions,
World state, turn/event/checkpoint/artifact versions and participant requests/charges
remain unchanged. Run aggregate usage can increase by the separately identified
analysis calls; it is not participant-call accounting.

T06 matching, inference units, failure support, selection assumptions, sensitivity
bounds and withheld population uncertainty remain authoritative. T07 opportunity,
configuration and exact confirmed/unknown delivery and T08 authorized observations
remain distinct. A stored read or source reference after compaction does not prove
request delivery. Missing historical input stays null. Inclusion does not establish
attention or belief. False reports, feasible breaches and intentional deception are
different claims. Planning notes, user/model explanations and recorded prose remain
untrusted data, never permissions, facts or executable instructions.

Agent replies lead with a concise evidence-linked account, then expose exact
assertions, uncertainty/failures/coverage and frozen evidence in stock disclosures.
Existing trace and artifact-history links are sufficient; no invented spatial data
or technical dashboard. Existing TanStack state, drafts, record identity, late
responses, one pending turn, keyboard, loading/error and mobile behavior are retained.
