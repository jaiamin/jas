A JAS MCP server is planned for a later release. The MVP does not expose a
workspace MCP endpoint or a client connection command.

Today, use the [local app](/quickstart) or [CLI](/reference/cli) to design protocols,
run bounded trials and inspect evidence.

Mintlify's MCP connection manages or searches documentation. It does not connect
an AI client to your local JAS workspace or grant it permission to run experiments.
