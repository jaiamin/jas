# Product brief

## Description
JAS runs controlled, replayable experiments on model-controlled agents. Explicit
rules determine observations, actions and consequences. A local workspace and CLI
produce reviewed records for a separate, model-free gallery.

## Primary audience
People designing and inspecting agent experiments on their own machines.
Assumption from the MVP spec: one researcher, not teams or hosted model runs.

## Jobs to be done
1. Install the MVP preview and watch a scripted example without a key.
2. Configure models and limits, define matched conditions and explicitly run.
3. Inspect evidence, verify replay, and review a record before publishing or forking.

## Motivation
Make agent comparisons measurable and shareable without an LLM deciding world
rules. Preserve private observations, exact evidence and explicit spending.
Replay verifies recorded consequences, not model identity or human validity.

## Presentation
Eight concise pages in Start, Guides and Reference. Reuse the app's pixel logo,
lowercase Bricolage wordmark, Geist, blue accents, white/graphite surfaces and
outlined icons. Prefer stock Mintlify layouts. JAS MCP is Coming soon.
Registry release and hosted-gallery readiness are separate from the docs;
the quickstart identifies the current MVP preview branch.
