# Treat participant harnesses as replaceable experimental factors

The user requires equal architectural attention to researcher and participant
harnesses. Participant systems therefore declare a replaceable harness for
planning, memory retrieval, investigation and verification alongside their
model, tools and effort limits. Every such operation remains subject to the
world's information and permission rules. This extends the current single-call
decision policy without disguising a harness change as a model-only improvement:
simple reference policies remain available, and comparisons identify the whole
participant configuration. No particular planning loop or memory policy is
presumed to improve behavior without a matched evaluation.

The user also accepted participant discretion within a declared effort budget:
the capable harness offers planning, retrieval, investigation and verification
without requiring every capability on every activation. Preserve a direct-action
reference harness and targeted ablations. Mandatory staged pipelines remain
possible as explicitly named experimental alternatives; their additional work
is not silently installed as a neutral default.
